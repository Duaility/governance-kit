### no-package-manager

- **Directive**: (Repo-local dogfood directive.) Nothing governance-kit ships invokes a package manager — `uv`, `pip`/`pipx`, `npx`, `pnpm dlx`, or `yarn dlx`. The scanned set is the executable-bearing content of the three shipped trees (tracked `*.sh` / `*.py` / `*.yml` / `*.yaml` under `kit/`, `packs/` and `skill/`) plus this repo's own `.githooks/*` dispatchers. Detection is command-position, not word-match: the tool name must sit at the start of a shell command (line start, after `;` `&` `|` `(` `$(`, or after a YAML `run:` key), so a prose mention in shipped docs or a docstring is not a violation.
- **Rationale**: Issue #355 locks the product's dependency posture — nothing in governance-kit's own machinery ever needs a package manager — and Q11 of that issue is explicit that *the kit should hold itself to it as a directive*. The commit path runs on bash + git (`no-commit-path-python`) and the shipped python runs on a bare `python3` (`stdlib-only-python`); reaching for `uv run --with X` or `npx X` to route around either rule defeats the posture as surely as a raw third-party import would — it is still a package manager doing an install at commit or run time, with all the same offline and drift failure modes. Three trees are out of scope because the kit does not ship them: `.github/workflows/**` (the documentation site is a genuine npm project and its workflow builds it), `scripts/**` (this repo's test harness), and `packs/*/directives/*/evals/**` (fixtures, which the materializer strips and which contain deliberate violation strings by construction). The vendored `.governance/` tree is out of scope too — it is materialized from the *last release* and lags the source trees by one cycle by design.
- **Enforced by**: `.governance/packs/duaility/governance-kit/directives/no-package-manager/check.sh` (repo-state; CI/run.sh) and `.githooks/pre-commit`.
- **Exceptions**: Path-glob waivers live in the sibling `defaults.conf` (empty by default) layered with the overlay `.governance/conf/duaility/governance-kit/no-package-manager.conf` — a bare line exempts a path from the scan, `!<path-glob>` un-exempts one of the shipped defaults. Reach for a waiver only to record a knowingly-accepted external constraint, never to launder a new violation.
