# scheduled-repo-with-lane

Same three installed directives as `scheduled-repo` (`secrets-hygiene`,
`license-headers`, `naming-convention`), plus an already-applied `nightly`
schedule lane:

- `.github/workflows/governance-schedule-nightly.yml` — generated by
  `governance schedule create nightly --cron "0 3 * * *" \
  --member governance-kit/core/secrets-hygiene \
  --member governance-kit/core/license-headers --evidence commits`.
- `.governance/install.yaml` carries the matching `install_assets_seeded`
  entry and `managed_digests` row for the workflow file.

Used by the "remove a lane" schedule eval — the lane exists so `governance
schedule remove nightly` has something real to delete.
