# scheduled-repo-with-lane

Same three installed directives as `scheduled-repo` (`secrets-hygiene`,
`license-headers`, `naming-convention`), plus an already-generated workflow:

- `.github/workflows/governance-schedule.yml` — generated by
  `governance workflow generate` from the two directives' non-empty
  `SCHEDULE_CRON` values. It has one `0 3 * * *` trigger and invokes each
  member independently.
- `.governance/install.yaml` carries the matching `install_assets_seeded`
  entry and `managed_digests` row for the workflow file.

Used by the "clear every cadence" workflow eval — the artifact exists so
`governance workflow generate` has something real to remove.
