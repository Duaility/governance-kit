### license-exists

- **Rule**: A `LICENSE` file (or an accepted variant such as `LICENSE.md`, `LICENSE.txt`, `COPYING`) exists at the repo root and is non-empty.
- **Rationale**: Without a license, the repo is legally ambiguous — downstream users cannot reuse or redistribute with confidence.
- **Enforced by**: `tests/governance/rules/license-exists.sh`
- **Exceptions**: none.
